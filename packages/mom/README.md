# Mom

The application skeleton for the Mom PHP framework, built on Laravel 13.

## Create a new app

```bash
composer create-project mom/mom my-app
```

Or use the [Mom installer](https://github.com/momphp/installer):

```bash
mom new my-app
```

## Development

```bash
composer run dev    # start the dev server, queue worker, log tail and Vite
composer test       # run the test suite
```

> This repository is a read-only split of [momphp/monorepo](https://github.com/momphp/monorepo). Open issues and pull requests there.
